API Reference

Bienvenido a la documentación oficial de la API de CyberShield. Nuestra API está diseñada sobre arquitectura REST, proporcionando endpoints predecibles orientados a recursos para gestionar auditorías de seguridad.

Todas las respuestas son devueltas en formato JSON estándar, incluyendo códigos de estado HTTP apropiados para indicar el éxito o fracaso de las peticiones.

Autenticación

Para interactuar con la API, debe autenticar sus peticiones mediante un Bearer Token. Puede generar su API Key desde el dashboard de su cuenta.

Incluya el token en la cabecera HTTP de cada petición:

Authorization: Bearer

Crear Escaneo

Inicia un nuevo análisis de seguridad sobre un objetivo específico (URL o IP).

POST /api/v1/scan
Parámetros del Body (JSON)
Nombre Tipo Descripción
target string La URL o dirección IP a analizar.
profile string Perfil de análisis: quick, full o stealth.
Ejemplo cURL 
curl -X POST https://api.cybershield.do/v1/scan \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "target": "https://example.com",
    "profile": "full"
  }'

Obtener Resultados

Recupera el informe detallado de un escaneo finalizado mediante su identificador único.

GET /api/v1/results/{scan_id}
Path Parameters
Nombre Tipo Descripción
scan_id uuid El ID único generado al iniciar el escaneo.
Respuesta Exitosa (200 OK) 
{
  "id": "7a2b...",
  "status": "completed",
  "findings": 12,
  "risk_score": 8.5
}

CVE Lookup

Consulta nuestra base de datos de vulnerabilidades conocidas (Common Vulnerabilities and Exposures) en tiempo real.

GET /api/v1/cve-lookup
Query Parameters
Nombre Tipo Descripción
q string Término de búsqueda (ej. "Apache 2.4", "CVE-2021-44228").
Ejemplo Python (Requests) 
import requests

url = "https://api.cybershield.do/v1/cve-lookup"
headers = {"Authorization": "Bearer YOUR_KEY"}
params = {"q": "log4j"}

response = requests.get(url, headers=headers, params=params)
print(response.json())
